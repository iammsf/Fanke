使用说明

Endpoint 是服务商 S3 API 地址，公开访问地址用于生成媒体 URL。请使用 HTTPS 与最小权限凭证。Session Token 仅临时凭证需要。

处理顺序固定为「图片处理 → 存储」。插件停用后停止新的 S3 上传，不删除已有文件。2026.10.27 · v1.3：配置移入插件页，新增多桶、别名与默认桶管理。
