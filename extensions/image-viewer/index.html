使用方法

文章正文中书写(顶格书写,行首不要缩进,否则会被 Markdown 当作代码块;说明文字写在标签内,也可用 des="…" 属性):

<fanke-img src="https://…/a.jpg" alt="A" des_pos="middle bottom" des_sty="fs=13,c=#666">图片描述</fanke-img>

token含义示例
hidden隐藏说明文字des_sty="hidden"
fs=像素说明字号fs=13
c=颜色说明文字颜色c=#666
bg=颜色说明背景色bg=#f5f5f5
bd=颜色说明描边(1px solid)bd=#ddd
b / i加粗 / 斜体des_sty="b,i"
w=百分比图片宽度(相对正文)w=60
r=像素图片圆角r=12

标签的 des_pos 覆盖默认位置;des_sty 按 token 合并:标签写了哪些 token 就覆盖哪些,其余沿用此处默认值(例如默认 b,fs=16,标签只写 c=#666 时仍会加粗、字号 16px)。多个样式 token 用逗号或空格分隔。

默认值在文章渲染时套用:改完这里保存后,已发布文章里没有写 des_pos / des_sty 的图片会立即跟着变化,不需要重新保存文章。

1.6 更新记录 · 2026.11.17

修复在可视化编辑器里直接改图注不入库：此前画布上的 des 属性被当成图注权威来源,用户在 figcaption 里改的文字保存时被旧值覆盖。现在一律以画布 figcaption 的实时文字为准,与文章页的取值顺序一致。

画布始终渲染 figcaption(隐藏图注用 display:none),因此清空图注会真的存成空,隐藏图注也不再丢失;figure 上不再写 des 属性。

修复历史内容丢图注：旧版渲染只认标签内文,把图注写在 des 属性里的老文章一进编辑器就被清空,现在会正确读出并回写为标签内文。

1.5 更新记录 · 2026.11.02

插件标签改为独立的 <fanke-img>说明</fanke-img>,不再占用原生 <img>,避免与普通图片互相干扰。

编辑器插图默认写入 <fanke-img>;新增「替换正文中的普通 <img> 标签」开关,开启后普通图片也按插件样式渲染。

1.4 更新记录 · 2026.10.31

修复文章页读取默认配置失败：公开通道 store.get_batch 的返回值是 {ok,data},此前按平铺结构解析导致默认 des_sty 一直为空。

标签 des_sty 改为按 token 与默认配置合并：标签没写的 token（如 fs、b）继续用默认值，不再整段覆盖。

1.3 更新记录 · 2026.10.31

默认位置与样式改为渲染时套用插件配置:修改默认值后,已发布文章中未自定义的图片自动生效。

后端保存时只补 </img> 闭合标签,不再把 des_pos="middle bottom" 写死进正文;历史文章里由旧版本自动写入的默认 des_pos 已一次性清理。

1.2 更新记录 · 2026.10.27

未设置 des_pos 时使用默认 middle bottom(水平居中、垂直图下);已保存的自定义全局默认位置仍有效,兼容旧配置 mid,标签显式属性优先。

显式闭合的 <img>说明</img> 即使省略 des_pos 和 des_sty 也会应用插件默认效果;普通未闭合且无 des / des_pos / des_sty 属性的图片不转换。
