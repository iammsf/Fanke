图片焦点选择器

在媒体库中为每张图片标注焦点(中心点 + 1:1 / 16:9 / 9:16 取景框); 前台与后台的缩略图会按容器宽高比自动选取对应焦点坐标进行裁切,保证重点内容不被切掉。

① 初始化:扫描媒体库

首次安装后,请扫描一次媒体库,为所有已存在的图片写入默认焦点(正中心)。已存在焦点数据的图片不受影响。

逐条检测焦点记录中的图片链接:浏览器与后端分别探测,两者均不可达才判定为无效(或运算保真,避免误删)。

使用说明

1. 启用本插件后,进入媒体库,任一图片卡片上点击 选择焦点;
2. 拖动 ⊙ 与三个虚线框,拖到右下角手柄可等比例缩放,点击右侧 √ 保存;
3. 前台文章封面、媒体库缩略图等会自动读取焦点数据:容器接近 1:1 用 1:1 框,接近 16:9 / 9:16 用对应框,其余用中心点;
4. 本页支持把焦点数据库导出备份、导入恢复、去重,以及清理已失效的图片链接。
